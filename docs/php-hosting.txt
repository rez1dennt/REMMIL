REMMIL — перенос на обычный PHP-хостинг

1. В панели хостинга выберите PHP 8.1 или новее (рекомендуется 8.3+), с расширением OpenSSL.
2. Содержимое public_html положите в публичную папку сайта. Она может называться public_html, www или именем домена.
3. Папку private положите УРОВНЕМ ВЫШЕ публичной папки, рядом с ней:

   папка-аккаунта/
     private/
       remmil-mail.php
       app.php
       catalog.json
       vendor/
     public_html/
       index.html
       api/lead.php
       css/
       js/
       assets/

Почта уже настроена для отправки заявок на 2009-parketdok@mail.ru через Mail.ru. Домен в private/remmil-mail.php можно оставить пустым: адрес страницы согласия определяется по запросу сайта. Composer и Node.js на хостинге не нужны.

Папка private должна быть доступна PHP для записи: обработчик создаёт storage для согласий и ограничения повторных запросов. Обычно подходят права 700 для private и 600 для конфигурации, если PHP работает от владельца аккаунта.

Включите HTTPS. На хостинге должен быть разрешён исходящий SMTP: smtp.mail.ru, порт 465, SSL/TLS. Если хостинг блокирует исходящую почту, её разрешает поддержка хостинга.

Архив содержит закрытую почтовую конфигурацию. Не кладите сам ZIP и папку private внутрь публичной папки сайта. В публичном GitHub реального пароля нет.

После переноса отправьте собственную заявку и проверьте входящие и «Спам». До размещения фактическая доставка на Mail.ru не проверялась: автоматические проверки используют только локальный SMTP-сервер и не отправляют внешние письма.

Если сайт открывается как файл, через статический Node-preview или GitHub Pages, PHP не выполняется. Верстка доступна, но заявка не отправляется и форма сообщает об этом.

Серверные записи согласия хранятся 90 суток. Очистка запускается при обращениях к форме. Для удаления без новых посещений настройте ежедневный запуск private/cleanup.php в cron. Обращения в почтовом ящике удаляет ответственный сотрудник в соответствии с политикой.

Официальные настройки Mail: https://help.mail.ru/mail/login/mailer/
PHPMailer 7.2.0: https://github.com/PHPMailer/PHPMailer/releases/tag/v7.2.0
