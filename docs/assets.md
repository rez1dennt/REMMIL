# Изображения и палитра

Изображения подготовлены встроенным ImageGen по предоставленным фотографиям товаров и утверждённому макету, затем оптимизированы в WebP с сохранением прозрачности. Это реконструированные каталожные изображения; для печати этикеток и юридически значимых надписей используйте оригинальные файлы производителя.

Файлы: interior.webp, mc90.webp, b90.webp, primer.webp. Суммарный вес четырёх рабочих изображений — около 433 КБ.

Основные целевые цвета: кремовый #F2EBE1; светлая поверхность #F8F5EF; подложка фото #E3EDF0; текст и цены #4A4743; заголовки #423E39; приглушённый синий #3D6686; тёмный низ #353B3C.

Слоган изменён по прямому указанию пользователя: «Основа прочных решений».

По последнему уточнению добавлены Lora (заголовки) и Manrope (интерфейс), локальные WOFF2 с кириллицей и латиницей. Лицензии SIL OFL в assets/fonts, исходные CSS Google Fonts сохранены в docs/font-source.css. Декоративный grain-lines.svg — тонкие линии по мотивам древесного рисунка; используется как нефункциональный фон с низкой непрозрачностью.
