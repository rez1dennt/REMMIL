# Материалы клиента: описания, логотип и свидетельство

Дата последнего уточнения: 12 ноября 2026 года.

## Согласованный объём

- Подробное описание каждого из трёх товаров: назначение, расход, состав, подготовка основания, применение и хранение. Расход виден сразу. По последнему уточнению подробности находятся в закрытых раскрывающихся строках; одновременно открыт один раздел. «Сертификаты» переключаются отдельно. CSS/JS версионируются по содержимому при сборке, чтобы браузер не смешивал старые файлы с новой разметкой.
- Использовать треугольный логотип REMMIL из PDF, сохранив геометрию знака и надписи. По последующему уточнению пользователя убрать фон и подготовить прозрачные SVG с тёмной надписью для шапки и светлой для подвала. Разместить на главной и юридических страницах. Палитру сайта и высоту шапки сохранить.
- Во вкладке документов каждого товара показать общее свидетельство на товарный знак № 1251523: уменьшенное изображение, ссылку на полное JPG и скачивание неизменённого исходного PDF. Явно обозначить принадлежность документа бренду, не выдавать его за сертификат качества товара.
- Подготовить отправку заявок на обычном PHP-хостинге через Mail.ru. Конфигурация с паролем остаётся локальной, игнорируется Git и поставляется только внутри закрытой части комплекта для хостинга. По указанию пользователя до размещения не подключаться к реальному SMTP и не отправлять внешних тестовых писем.

## Реализация и проверка

1. Подготовить изображения из оригинального PDF, скопировать исходный PDF, сверить контрольные суммы.
2. Обновить данные описаний и общий блок документов; сохранить существующие документы отдельных продуктов.
3. Подключить логотип к общей шапке и подвалу, обновить генератор юридических страниц и значок вкладки.
4. Проверить доступность фото и PDF, скачивание оригинала, все состояния каталога и меню, основные размеры 1280 / 768 / 360 / 320 px и существующие тесты. Обновить архив и GitHub.
